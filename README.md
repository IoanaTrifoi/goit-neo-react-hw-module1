# React Homework 01 - Components and Styling

This project is a collection of reusable React components developed as part of the **GoIT Neo React Course (Module 1)**. The focus is on building a modular architecture, passing data via props, and styling components using **CSS Modules**.

##  Live Demo
You can view the live version of this project here:
[**Live Page on Vercel**](https://goit-neo-react-hw-module1-beta-ten.vercel.app/)

##  Technologies Used
* **React** (Functional Components)
* **Vite** (Build Tool)
* **CSS Modules** (Scoped Styling)
* **Modern Normalize** (CSS Reset)
